# Configuraciones

Esta carpeta contiene los artefactos de configuración que acompañan la documentación.

## Running-configs

Las salidas reales y finales deben guardarse en `running-configs/`. No se deben sustituir por configuraciones reconstruidas de memoria.

## FortiGate

La configuración funcional del FortiGate se realizó por GUI según la consigna. Los archivos de esta carpeta deben tratarse como registros técnicos y no como sustituto de la demostración por GUI.
